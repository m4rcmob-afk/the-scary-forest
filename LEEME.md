## Archivos para publicar

Sube TODO el contenido de esta carpeta a la raíz de un repositorio público:
- index.html: portal completo con sus imágenes incrustadas.
- TheScaryForest-Juego/: versión Web de Unity, incluida su carpeta Build.
- .nojekyll: evita el procesamiento de Jekyll.

No cambies el nombre de TheScaryForest-Juego sin actualizar sus enlaces en index.html.

En GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
El enlace tendrá el formato https://m4rcmob-afk.github.io/NOMBRE-DEL-REPOSITORIO/.
Para subir el archivo de datos del juego, usa GitHub Desktop o Git: pesa más de 25 MB y la carga manual de archivos en el navegador puede rechazarlo.

## Probar localmente

Sirve la carpeta con un servidor HTTP. Abrir el HTML directamente con file:// permite revisar el portal, pero Unity requiere un servidor HTTP/HTTPS para cargar sus archivos.

## Actualizar el juego

Genera otra compilación Web desde Unity y reemplaza el contenido de TheScaryForest-Juego conservando ese nombre de carpeta. El portal permanece igual.

## Validación

Se comprobó la carga de Unity dentro del portal, las imágenes, los créditos, los enlaces internos, la ampliación de las láminas y la presentación adaptable. La publicación pública en GitHub Pages todavía debe realizarse.
